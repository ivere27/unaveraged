영수증 읽기 설정

이 브라우저에 설정을 저장합니다. 영수증과 추론 결과는 기기 밖으로 전송하지 않습니다.

감시할 페이지와 영역

정확한 호스트를 입력하세요. 경로에는 *를 사용할 수 있습니다. 비우면 자동 감시가 꺼집니다. 새 사이트를 저장하면 접근 권한을 요청하며, 해당 페이지를 새로고침해야 적용됩니다.

비우면 문서 전체를 감시합니다. 아래 선택자는 이 영역 안에서 찾습니다.

추론과 메모리

각 워커가 모델을 별도로 로드하므로 워커 수를 늘리면 메모리 사용량도 증가합니다. 한 번의 모델 추론은 영수증 1개를 처리합니다.

기본 60,000ms = 1분. 10초~30분 사이로 설정합니다. 요청이 끝난 뒤 유휴 시간이 지나면 추론 워커와 모델 메모리를 해제하고, 다음 요청에서 다시 로드합니다. 페이지 감시 UI는 남아 있습니다.

답변 제출

기본값은 꺼짐입니다. 켜면 지정한 제출 버튼을 자동으로 누릅니다.

히트맵 표시

기본값은 켜짐입니다. 실제 추론에서 계산된 공간별 attention을 원본 이미지 위에 겹쳐 표시합니다. 확장 팝업에서도 최근 영수증과 히트맵을 확인할 수 있습니다.

프로파일링

기본값은 꺼짐입니다. 연산별 실행 시간과 메모리 요약, 워커·대기열·캐시·오류 기록을 확인할 수 있습니다. 기록을 켜면 처리 비용이 늘어날 수 있습니다.

현재 실행 상태 및 프로파일링

새로고침할 때만 조회합니다. 상태 조회는 추론을 시작하거나 유휴 시간을 연장하지 않습니다. 모든 측정치는 기기 내에서만 처리됩니다.
